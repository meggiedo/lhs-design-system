# Longhorn Studies Design System

This site shows every color, text style, spacing value and component from the **LHS Design System** Figma file, built as real, clickable code.

**How to use it**

- Use the menu on the left. **Foundations** has colors, type, spacing, shadows and icons. The groups below it match the groups on the Figma components page.
- Click a component, then a version (like *Primary* or *Closed*) to see it on its own.
- The **Controls** panel under each component lets you change its text and options (like *Saved* or *Status*) without any code.
- Components you can click in the app also work here: chips and bookmarks toggle, the search bar takes typing, and the nav switches tabs.

**Where things come from**

- Figma: [LHS Design System](https://www.figma.com/design/AOmpyTZupE8rJOp1Tdm9vo/LHS-Design-System)
- Names match Figma: the Figma color `text/primary` is `--color-text-primary` in code, and the text style `body.medium.strong` is the class `lhs-body-medium-strong`.
- Font: Figtree. Icons: Phosphor (regular, and fill for active states).

When the Figma file changes, ask Claude to update this site and it will republish on its own.
